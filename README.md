# SOC Page Refresh & Keyword Monitor

Production-grade Google Chrome extension (Manifest V3) designed for Security Operations Center (SOC) analysts and site monitors. Features auto-scheduled tab reloads, a live 2-digit toolbar countdown, non-overlapping exact-string detection, non-intrusive translucent page alerts, and desktop notifications.

---

## Installation Guide

1. Clone or save all project files into a folder named `SOC_Page_Refresh_Monitor`.
2. Generate the icon PNG assets:
   ```bash
   python3 generate_icons.py
